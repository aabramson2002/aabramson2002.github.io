    Projects

    JSON Generator

    The JSON Generator is a personal project designed to automate the process of converting Excel data exported from SAP into JSON for Safilo's warehouse operations. The generated JSON is sent through Postman to Tompkins T-Sort robots, which use the data to route eyewear to the appropriate shipping areas. The application originally accepted CSV files before being redesigned to work with Excel using the SheetJS library. It processes both line-item and handling-unit data and is now used to support warehouse shipping operations.

    Contract & Vendor Database

    I developed a SQL-based database for Safilo's ICT department to manage its financial and vendor information. There are two different tables for the database. One focuses on the contracts themselves and the other focuses on the vendors. The vendor table has the list of contacts to reach out to if a contract is near its end. The contract tables focus on the product itself, providing many columns including cost, currency, destination, product request and product order number. On the front-end, it uses a web-based UI that guides users into navigating, adding, removing, and creating entries to analyze and edit the SQL data. I designed the editing interface to resemble an Excel spreadsheet because that was the workflow the team was already familiar with. The database is now used by the ICT team for its annual financial reporting and long-term record keeping.

    Innovation Monthly Newsletter

    During my internship at L'Oréal, I redesigned and automated the process used to create the Online + Offline Innovation team's monthly newsletter. The original newsletter was manually assembled in MailChimp and could take more than a week to complete. I rebuilt portions of the HTML, including a responsive, mobile friendly button, and reduced the amount of code by over half. I then moved the newsletter to an excel spreadsheet to automate the process of creating it. The HTML is divided into rows where there is an empty column in each row for each updatable section in the newsletter. The new process reduced production time to a few days and continues to be used by the team.
